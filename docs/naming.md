# Repository naming

Recommended product name: **MarketAtlas**.

Repository: **thatquantguy44/MarketAtlas** — the owner selected this name and initialized the repository.

The name communicates a map of markets and relationships, accommodates both macro and instrument data, and leaves room for securities-finance applications. The description should carry the technical terms so the name stays readable on a GitHub pin.

| Candidate | Strength | Tradeoff |
| --- | --- | --- |
| MarketAtlas | Clear market focus and broad future scope | General name; pair with a precise description |
| MarketLattice | Strong quant and interconnected-data feel | Less immediately understandable to general reviewers |
| MacroGraph | Obvious macro/graph connection | Narrower than the eventual instrument and securities-finance scope |
| MarketWeave | Memorable relationship metaphor | Technical purpose depends on the description |

The GitHub namespace is confirmed as `thatquantguy44/MarketAtlas`. Alternative names are retained as design notes. Domain, trademark, and package-registry availability have not been checked.
